# SetLedger

Clubs pay licensing; the producers a DJ actually played rarely see it. SetLedger turns a set
recording into a timestamped, PRS-ready tracklist matched against the DJ's own crate.

Built during dev.to Hacktoberfest 2026 Week 2 ("Side Hustle"), Oct 12–18. Planning for this
entry (idea research and judging notes) was done before the first commit and lives outside
this repository.
